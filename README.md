# 拾光裁切 · 安装与更新

此仓库用于发布拾光裁切的安装程序、更新说明和第三方分发资料，不存放用户视频或私有工程仓库。

## 当前状态

Windows 1.3.0 自动更新功能正在准备发布。尚无可供公众下载的正式版本；不要将发布草稿视为已完成 Windows 实机验收。

计划体验：自动检查版本 → 用户点击下载 → 校验安装包 → 空闲时点击重启更新。导出期间不会强行重启。

Windows 旧 ZIP 版需手动安装一次新的安装程序；Mac 自动更新需要后续签名与发布配置。

## 发布前检查

- Windows 实机验证首次安装、覆盖升级与重启。
- 核齐随包 FFmpeg 二进制及外部库对应源码、构建资料和许可证。
- 核验安装包、blockmap 和版本清单的版本与哈希一致，最后开放正式 Release。

本仓库目前只公布发布说明，安装包暂不公开。
